# Non-rectangular generators

This batch adds four editable beta generators covering five source drawings. Book entries use `SPD-` identifiers and their own catalog category and SVG filename prefix. They are not FEFCO codes. Dimensions are in millimetres; pillow width is developed panel width, and polygon side length is identified explicitly.

| Generator              | Source                                  | Construction and controls                                                                                                                                                                                                                   |
| ---------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SPD-pillow-pack        | Structural Package Designs, pp. 305–306 | Curved end creases, two panels and glue joint; closureVariant 0 uses a glued seam, 1 uses a tuck tongue and receiving slit. Length, panel width and curve depth edit both cuts and creases. Tuck depth and tongue width apply to variant 1. |
| SPD-hexagonal-ring-box | Book p. 299                             | Two hexagonal caps attached to a three-wall strip, plus a separate three-wall belt. Editable hexagon side length, height, cap flanges, glue joint, material thickness and part spacing.                                                     |
| 0459                   | FEFCO 2022 p. 66; book p. 130           | Elongated eight-sided tray, crease-separated walls and corner gluing ears. Editable base length/width, wall height and corner clipping.                                                                                                     |
| 0858                   | FEFCO 2022 p. 116                       | Eight-wall tube with top return flaps, four integral crease-sided corner supports and a separate fitted octagonal base. Editable width across parallel faces, height, flap depth, radial fit, glue joint and spacing.                       |

The book's octagonal tray remains routed to canonical `fefco:0459`; no separate book generator was created. Both pillow drawings remain variants of `spd:pillow-pack`. The ring box differs from polygon tubes by its attached pair of caps and three-wall complementary belt. FEFCO 0858 differs from implemented 0859 by its fixed eight-sided body and four folded corner supports. Pillow curved lens creases do not appear in the polygon tray/tube construction families. These comparisons preserve the existing canonical identities; other book comparison tasks remain gated.

These are dimension-driven interpretations of schematic source drawings, not production-certified tooling. In particular, trial-cut the curved creases, tuck tongue receiver, ring belt/cap fit and octagonal tray corner glue ears. Thickness compensation is an initial allowance, and pillow interior volume is not derived from rectangular L/W/H.

Run `npm run generators:manifest`, `node_modules/.bin/vite-node scripts/book-generator-assets.ts`, then `python3 scripts/build-implementation-backlog.py` to refresh coverage, original generated book thumbnails and backlog. Book pages are referenced, not copied into the repository.
